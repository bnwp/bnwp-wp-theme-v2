## Why GPL and not something more permissive

This theme is a derivative work of the v1 theme in
[bnwp/bnwp-wp-theme](https://github.com/bnwp/bnwp-wp-theme), which is
GPL-2.0-or-later. It carries over that theme's content model, its bilingual
layer, its date and numeral handling and its admin fields. A derivative of
GPL code stays GPL: it cannot be relicensed without the agreement of every
copyright holder, which here includes the v1 authors.

WordPress itself is GPL, and themes that call its APIs are expected to be
GPL-compatible. This repository briefly carried an MIT `LICENSE` file created
with the repository; that was an oversight and contradicted the licence
declared in `style.css`. It has been corrected.
